# 메소 알러지 쌀숭이

메이플스토리 인벤토리 사진에서 재화(메소·아이템)를 읽어 날짜별로 기록하고, 캐릭터 경험치 성장을 추적하는 모바일 친화 웹앱(PWA)입니다.

## 주요 기능

### 쌀 탭 — 재화 기록
- **사진으로 읽기**: 인벤토리(소비 탭, 기타 탭) 스크린샷을 올리고 각 아이템이 있는 위치를 사각형으로 지정하면 OCR로 개수를 인식합니다.
  - 추적 아이템: 코어 젬스톤, 순록의 우유, 황혼의 이슬, 주문의 흔적, 솔 에르다 조각, 보유 메소
  - 여러 칸에 나뉜 아이템은 사각형을 여러 개 그려 합산할 수 있습니다.
  - 인식 결과는 직접 수정할 수 있고, 사진 없이 직접 입력해도 됩니다. `109억 2633만 1586`처럼 억/만 단위 표기를 지원합니다.
- **아이템 단가**를 설정하면 보유 메소와 아이템을 합친 **환산 총 자산**을 계산합니다.
- **일자별 기록**: 전일 대비 증감을 표시합니다(빨강 증가 · 파랑 감소).

### 성장 탭 — 캐릭터 경험치
- 넥슨 Open API로 캐릭터 레벨과 경험치를 조회해 매일 기록합니다(넥슨은 전일 기준 데이터를 제공).
- 다음 레벨까지 남은 경험치, 하루 평균 획득량, 달성률, 예상 레벨업 일자를 보여줍니다(기록 2일치 이상 필요).

## 실행

별도 빌드 없이 정적 파일만으로 동작합니다.

```bash
python3 serve.py          # 기본 8000 포트
python3 serve.py 5500     # 포트 지정
```

브라우저에서 `http://localhost:8000` 으로 접속합니다. `serve.py`는 정적 파일 서빙과 함께 `/nexon/...` 요청을 `https://open.api.nexon.com`으로 중계합니다. 브라우저가 넥슨 API를 직접 호출하면 CORS 사전 요청에서 막히기 때문입니다.

휴대폰에서 경험치 조회를 쓰려면 설정의 **넥슨 중계 서버 주소**에 중계 서버(예: Cloudflare Workers) 주소를 입력해야 합니다.

## 기록 동기화 (GitHub)

기록은 기본적으로 브라우저에만 저장되어 쿠키/사이트 데이터를 지우거나 다른 브라우저에서 열면 사라집니다. 기록을 GitHub **데이터 전용 저장소**에 `data/<닉네임>.json`으로 보관하면 어느 기기에서든 닉네임으로 불러올 수 있습니다. 대상은 일자별 재화 기록과 경험치 기록입니다.

- 저장소 주소는 `sync.js` 상단의 `REPO` 값입니다(기본 `Bad-day/MapleStory_ssal_data`).
- **읽기**는 토큰 없이 되고, **쓰기**는 설정에 넣은 GitHub 토큰이 있을 때만 됩니다. 토큰이나 닉네임이 없으면 이전처럼 이 기기에만 저장됩니다.
- 데이터 저장소가 공개라서 닉네임을 아는 사람은 누구나 기록을 볼 수 있습니다.

### 준비 (소유자, 한 번만)
1. 데이터 저장소를 만듭니다. 공개(Public)로 만들고 README로 초기화해 `main` 브랜치가 있게 합니다.
2. 같이 쓸 사람마다 GitHub에서 **Fine-grained personal access token**을 발급합니다.
   - Repository access: 데이터 저장소 하나만 선택
   - Permissions: **Contents → Read and write**
   - 토큰이 데이터 저장소에만 권한이 있어 앱 코드는 바꿀 수 없습니다. 문제가 생기면 그 토큰만 폐기하면 됩니다.

### 사용
1. 설정에서 **캐릭터 이름**과 **GitHub 토큰**을 입력합니다.
2. 새 기기라면 **기록 불러오기**를 누릅니다. 저장된 기록이 있으면 불러옵니다.
3. 이후 저장할 때마다(경험치 자동 기록 포함) 1~2초 뒤 GitHub에 반영됩니다. 상태는 설정 화면에 표시됩니다.
4. 같은 닉네임을 쓰는 기기끼리 같은 기록을 공유합니다. 동시에 두 기기에서 저장하면 나중에 저장한 쪽이 이깁니다.

### 공유 링크 (토큰 입력 없이 쓰기)
사용자가 토큰을 직접 입력하지 않아도 되도록, 닉네임과 토큰을 **암호화해서 링크에 붙여** 전달할 수 있습니다.

1. 앱 주소 뒤에 `link.html`을 붙여 엽니다. (예: `https://bad-day.github.io/MapleStory_ssal/link.html`)
2. 닉네임(선택), GitHub 토큰, **암호**를 입력하고 **링크 만들기**를 누릅니다. 입력값은 화면 안에서만 쓰이고 전송되지 않습니다.
3. 만들어진 링크와 암호를 **서로 다른 경로**로 전달합니다. (예: 링크는 단톡방, 암호는 따로 귓속말)
4. 받는 사람은 링크를 열고 암호를 한 번 입력하면 닉네임과 토큰이 그 브라우저에 저장됩니다. 이후엔 입력이 필요 없습니다.

토큰은 AES-GCM(암호는 PBKDF2로 키 변환)으로 암호화되며 링크의 `#` 뒤에 들어갑니다. `#` 뒤는 서버로 전송되지 않고 저장소에도 남지 않습니다. 암호가 약하면 링크를 가진 사람이 추측해서 풀 수 있으니 충분히 길게 정하세요. 문제가 생기면 해당 토큰만 폐기하고 새 링크를 만들면 됩니다.

## 설정

앱 설정 화면에서 입력합니다.

| 항목 | 설명 |
| --- | --- |
| 넥슨 Open API 키 | [넥슨 Open API](https://openapi.nexon.com)에서 발급 (메이플스토리 포함 필요) |
| 캐릭터 이름 | 경험치를 조회할 캐릭터 |
| 넥슨 중계 서버 주소 | 로컬 프록시 또는 외부 중계 서버 |
| 아이템 단가 | 환산 총 자산 계산용 |
| GitHub 토큰 | 기록을 데이터 저장소에 저장할 때 필요 (선택) |

API 키와 GitHub 토큰은 **이 기기의 브라우저(localStorage)에만 저장**됩니다. 기록은 동기화를 켜지 않으면 이 기기에만 저장됩니다.

## PWA / 오프라인

- `manifest.webmanifest`로 홈 화면에 설치할 수 있습니다.
- `sw.js`가 앱 껍데기를 캐시해 오프라인에서도 실행됩니다. 사진 판독(OCR 엔진 최초 다운로드)과 넥슨 조회만 네트워크가 필요합니다.
- 넥슨 API 응답은 캐시하지 않습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 진입 페이지 |
| `app.js` / `app.css` | 번들된 React 앱과 스타일 |
| `serve.py` | 로컬 정적 서버 + 넥슨 API 중계 프록시 |
| `sync.js` | GitHub 데이터 저장소 동기화, 공유 링크 해독 |
| `link.html` | 공유 링크 만드는 화면 |
| `sw.js` | 서비스 워커 |
| `manifest.webmanifest`, `icon-*.png` | PWA 메타데이터와 아이콘 |
| `tess/` | Tesseract.js OCR 엔진(워커, WASM 코어, 영어 학습 데이터) |

## 사용 기술

React, [Tesseract.js](https://github.com/naptha/tesseract.js)(브라우저 내 OCR), 넥슨 Open API, Python 표준 라이브러리(`http.server`).
